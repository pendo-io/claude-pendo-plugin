# Pendo Orchestrate

Create and configure draft Orchestrate email journeys via Pendo MCP — multi-email journeys and conditional split flows.

## Skill

`create-orchestrate-journey` — intake, create, verify, and optionally set audience, schedule, and goal.

Connect Pendo MCP: https://support.pendo.io/hc/en-us/articles/41102236924955-Connect-to-the-Pendo-MCP-server
