# Pendo Orchestrate

Create, configure, and edit draft Orchestrate email journeys via Pendo MCP — multi-email journeys and conditional split flows. Activation stays in the Orchestrate UI.

## Skill

`orchestrate-journeys` — lifecycle skill: create, configure, edit, and hand off for activation (dispatch by user intent; content craft per message type).

Connect Pendo MCP: https://support.pendo.io/hc/en-us/articles/41102236924955-Connect-to-the-Pendo-MCP-server
